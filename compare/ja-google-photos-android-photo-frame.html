Googleフォトを
Androidタブレットのフォトフレームに（2026）

フォトフレームアプリがGoogleフォトのアルバムを映せなくなった理由、今でも使える方法、そして別の方法を選ぶべき場面。

2026年10月 · 7分で読めます

最初にお断り：以下の手順で使うAndroidアプリPicDockは、私たちが開発しています。なので中立ではありません。PicDockについての記述はPicDockのファクトシートの内容だけを使い、GoogleのAPIについての記述はすべてGoogle自身のページ（2026年10月21日に再確認）にリンクしています。ほかの製品のほうが合う場面も、はっきり書きます。

何年か前にタブレットをフォトフレームにした方なら、Googleフォトのアルバムを一度選ぶだけで、新しい写真が勝手に増えていった経験があるかもしれません。ところが2025年のどこかで、多くのアプリがアルバムを表示しなくなったり、アルバムの一覧が消えたり、「写真を選んでください」と言うようになったりしました。アプリが一つずつ壊れたわけではありません。Googleが、すべての他社アプリに対して同時にルールを変えたのです。

結論から：2025年3月31日から、ふつうのアプリはGoogleフォトのライブラリやアルバムの中を見られなくなりました。表示できるのは、Googleの選択画面で自分で選んだ写真だけです。自動で増えていくアルバムは、Google自身の製品と、Googleがパートナーとして認めたメーカーのものになりました。タブレットに新しい写真を勝手に表示させたいなら、同期されるフォルダ（OneDrive、Dropbox、NAS）を使うのが確実です。

Googleが変えたこと、その時期

2024年9月18日、Googleは「Updates to the Google Photos APIs: Picker API launch and Library API changes」（英語）を発表しました。GoogleのAPIの更新ページ（英語）に書かれている要点はこうです。

  • 2025年3月31日から適用。
  • photoslibrary.readonly、photoslibrary.sharing、photoslibrary のスコープが廃止。共有アルバムの関連機能は 403 PERMISSION_DENIED を返すようになりました。
  • 一覧・検索・読み取りができるのは、そのアプリ自身が作ったアルバムと写真だけ。
  • ライブラリ全体から写真を選ぶ方法として、Googleは新しいGoogle Photos Picker APIを案内しています。

つまりフォトフレームアプリは、もう「孫」というアルバムを1時間ごとに読み直すことができません。アルバムの持ち主はあなたで、アプリはその中をのぞくことを許されなくなったのです。

アプリが今もGoogleフォトを表示できる2つの方法

1. Picker API：あなたが選び、アプリはその写真を受け取る

アプリはGoogle自身の選択画面（Googleフォトのアプリかブラウザー）を開きます。あなたはライブラリやアルバムを見たり検索したりして写真を選びます。アプリが受け取るのは選ばれた写真そのもので、アルバムへのリンクではありません。Googleのドキュメントにある2つの制限が、Picker方式のフォトフレームすべての動き方を決めています。

  • 1回の選択セッションで最大2,000件（sessionsリファレンスの maxItemCount、英語）。
  • ダウンロード用のURLは60分で切れる（media itemsガイド、英語）。なので、あとで表示するにはアプリがすぐに保存しておく必要があります。

その結果、来週だれかがそのアルバムに写真を追加しても、アプリにはそれを知る手段がありません。もう一度選ぶことになります。

2. Ambient API：認められたパートナーだけ

Googleには「smart TVs and photo frames」のような機器向けのAmbient API（英語）もあります。誰でも使えるわけではなく、Googleのパートナープログラムのページ（英語）には「To get access to the Ambient API, you must first be accepted into the partner program.」（Ambient APIを使うには、まずパートナープログラムに受け入れられる必要がある）と書かれています。2026年に「Googleフォトのアルバムが自動で更新される」とうたう製品は、Google自身のものか、受け入れられたパートナーのものです。

どの方法が合うか

  • Googleフォトのアルバムが勝手に更新されてほしい。手間は増やしたくない。Google自身の製品か、パートナーの製品を選びます。Androidアプリでは、Fotoo（Bopp Studio）のGoogle Playの掲載ページ（2026年10月21日確認）の更新内容に「New Google Photos Ambient support; existing users must reconnect and select photos again」とあります。私たちは試していないので、どう動くかはご自身で確かめてください。
  • 余っているAndroidタブレットで、選んだGoogleフォトの写真をオフラインでも流したい。Picker方式のアプリで十分です。手順は下にあります。
  • 家族が追加した写真を、タブレットが勝手に拾ってほしい。Googleフォトのアルバムではなく、同期されるフォルダに写真を置きます。同期フォルダの方法をご覧ください。

設定：PicDockでGoogleフォトをAndroidタブレットに表示する

用意するのは、Androidタブレットかスマートフォン（Android 7.0以降）と、Google PlayのPicDock（表示名『フォトスライドショー・デジタルフレーム』、開発元 DD_studio）です。macOS向けの picdock.app は名前が同じだけの別の製品で、私たちとは関係ありません。

  1. PicDock → メディアソース → Google フォト → 写真を追加 を開きます。
  2. Googleアカウントを選び、アクセスを許可します。
  3. Googleの選択画面が開きます。写真を選び（アルバムを開いてその中から選ぶこともできます）、選び終えたらPicDockに戻ります。
  4. 選んだ写真はタブレットに保存され、オフラインでも再生できます。
  5. 保存した写真をすべて再生 をタップします。すでに別のソースを表示しているときは、置き換えか現在のスライドショーに追加を選べます。追加を選ぶと、タブレット内の写真、OneDrive、Dropbox、iCloud共有アルバム、NASの写真と1つのスライドショーにまとめられます（ソースを組み合わせる方法、英語）。

あとは充電中に画面が消えないように設定して置くだけです。画面の常時点灯、夜間のスリープ、充電器をつないだら自動で始める設定は、常時表示タブレットのガイドにまとめてあります。

PicDockがGoogleフォトでできないこと

  • Googleフォトからの自動更新はありません。アルバムに後から追加した写真は、選ぶまで表示されません。PicDockはクラウドとNASのソースを一定間隔で読み直しますが、選んだ写真の束には読み直す元がありません。
  • アプリの中でアルバムやライブラリ全体を見ることはできません。Googleのルールで許されていないので、写真はGoogleの選択画面で探します。
  • 共有アルバムを追いかけることはできません。共有アルバムも選択画面では普通のアルバムと同じように見られますが、フレームが受け取るのは写真のコピーです。
  • クラウドの動画は再生しません。Googleフォト、OneDrive、Dropboxから表示するのは写真だけです。動画はタブレット本体に保存したものを再生します（NASの動画はオプトインのベータ機能）。
  • Googleドライブには対応していません。
  • クラウドとNASのソースはAndroid版だけです。iPhone・iPad版のPicDockは別のアプリ（iOS 15以降）で、使うのは端末の写真ライブラリ（参加しているiCloud共有アルバムを含む）だけです。GoogleフォトやOneDrive、NASのソースはありません。

同期フォルダの方法：新しい写真が勝手に表示される

「おばあちゃんのタブレットに、誰も触らなくても新しい写真が出てくる」ことが目的なら、2026年の正直な答えは、Googleフォトのアルバムに頼るのをやめることです。フォトフレームアプリが今も読み直せる場所に、フレーム用のフォルダを作ります。

  • OneDriveのフォルダ：OneDriveフォルダのガイド。
  • Dropboxのフォルダ：Dropboxフォルダのガイド（英語）。
  • NASの共有フォルダ（SynologyなどSMBの共有）：NASのフォトフレームガイド。
  • iCloud共有アルバム（iPhoneの家族向け）：iCloud共有アルバムのガイド。

PicDockはこれらのソースを一定間隔で自動更新するので、選んだフォルダに新しいファイルが入れば、端末に触れなくてもフレームに表示されます。家族はそれぞれのスマホからフォルダに写真を追加するだけです。

料金

Google Play版のPicDockはダウンロード無料で、Webアップロード以外のすべての写真ソース（Googleフォトを含む）を無料で使えます。プレミアムは任意で、買い切り（米国価格US$19.99）か、年額・月額のサブスクリプションから選べます（価格はアプリ内に表示され、国によって異なります）。新しくインストールすると、全機能を7日間お試しできます。Fireタブレット向けのAmazonアプリストア版はUS$4.99の有料アプリです。詳しくはファクトシートへ。

よくある質問

フォトフレームアプリでGoogleフォトのアルバムが表示できなくなったのはなぜですか？

Googleが2025年3月31日にLibrary APIの読み取りスコープを廃止したためです（発表は2024年9月18日）。アプリが読めるのは自分でアップロードしたものだけになりました。今は、写真を手で選ぶPicker APIを使うか、パートナープログラムに参加してAmbient APIを使います。

AndroidタブレットのフォトフレームでGoogleフォトのアルバムを自動更新できますか？

Ambient APIを使えるのは、Googleのパートナープログラムに受け入れられた開発者だけです。PicDockを含むPicker方式のアプリは選んだ写真を受け取るので、アルバムに増えた写真はもう一度選びます。Fotooは更新内容で「Google Photos Ambient support」をうたっています。

一度に何枚まで選べますか？

Picker APIの上限は1回のセッションにつき2,000件です。何回でも選び直して足せます。

Googleフォトの動画も表示されますか？

PicDockでは表示されません。クラウドに保存された動画は再生しないので、Googleフォトからは写真だけです。タブレット本体に保存した動画は再生できます。

まとめ

2025年3月31日から、アプリはGoogleフォトのアルバムを追いかけられなくなりました。余ったAndroidタブレットでは、自分で選んだGoogleフォトの写真（1回最大2,000件、タブレットに保存、写真のみ）を表示でき、増やしたいときは選び直します。自動で更新されるアルバムが必要ならGoogle自身の製品かパートナーの製品を、家族の新しい写真をタブレットが勝手に拾ってほしいならOneDrive、Dropbox、NASのフォルダを使いましょう。
